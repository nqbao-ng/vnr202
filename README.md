# Từ chuyển hướng chiến lược đến Cách mạng Tháng Tám 1945

Bài thuyết trình web tương tác gồm 9 phần, trình bày quá trình từ chuyển hướng chiến lược giải phóng dân tộc đến thắng lợi của Cách mạng Tháng Tám năm 1945.

## Chạy cục bộ

```bash
pnpm install
pnpm dev
```

## Kiểm tra bản production

```bash
pnpm build
pnpm preview
```

Các liên kết nguồn nội dung và hình ảnh được hiển thị ngay dưới tư liệu hoặc trong mục **Nguồn kiểm chứng** ở cuối từng phần.
